# 提示词模板

本文件包含 DeepResearch 技能常用的提示词模板。

---

## 1. 基础搜索提示词

### 快速信息检索

```
请帮我搜索 [主题] 相关的最新信息。

搜索关键词: [关键词1, 关键词2]
期望结果: [具体需求描述]
```

### 示例

```
请帮我搜索 Python 异步编程相关的最新信息。

搜索关键词: python async asyncio 2025
期望结果: 最新的最佳实践和教程
```

## 2. 深度研究提示词

### 主题深度研究

```
请对 [主题] 进行深度研究，包括：
1. 背景和定义
2. 核心概念和原理
3. 最新发展趋势
4. 实际应用场景
5. 相关资源和工具

请先进行搜索，然后对重要资源进行深度提取。
```

### 示例

```
请对 "大语言模型 Agent 技术" 进行深度研究，包括：
1. 背景和定义
2. 核心概念和原理

4. 实际应用场景
5. 相关资源和工具

请先进行搜索，然后对重要资源进行深度提取。
```

## 使用建议

1. **先搜索后深入**: 使用基础搜索获取概览，再使用深度研究进行深入
2. **明确需求**: 在提示词中清楚说明期望的结果格式
3. **迭代优化**: 根据初始结果调整搜索策略
4. **记录来源**: 重要信息标注来源，便于后续引用
