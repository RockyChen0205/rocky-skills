# 使用示例

本文档展示 DeepResearch 技能的常见使用场景。

---

## 示例 1: 快速信息搜索

### 场景
用户想了解某个技术的最新发展

### 用户请求
```
帮我搜索一下 Claude Code 的最新功能更新
```

### 工作流
1. 使用 MiniMax web_search 搜索 "Claude Code 最新功能 2025"
2. 分析搜索结果，提取最新功能信息
3. 整理并呈现给用户

### 预期输出
最新的 Claude Code 功能更新列表，包含版本号和新功能描述

---

## 使用技巧

1. **明确需求**: 越具体的请求，搜索结果越准确
2. **分步进行**: 复杂问题可以分多次搜索，逐步深入
3. **验证信息**: 多个来源交叉验证重要信息
4. **记录来源**: 重要信息记录来源，便于后续引用
5. **迭代优化**: 根据结果调整搜索策略
