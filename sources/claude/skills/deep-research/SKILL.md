# DeepResearch 深度研究助手

## 概述

这个技能提供了一套完整的研究工作流，用于：
- 网页信息搜索
- 网页内容提取与分析
- 学术论文搜索
- 文件解析与内容提取
- 音视频内容分析

## 工具映射

| 功能 | 工具 | 状态 |
|------|------|------|
| 网页搜索 | MiniMax MCP `web_search` | ✅ 已配置 |
| 网页内容提取 | Jina Reader | ✅ 免费可用 |
| 学术搜索 | Serper | ✅ 已配置 |
| 文件解析 | Dashscope | ⏳ 需申请 |
| 音视频分析 | Dashscope qwen-omni | ⏳ 需申请 |

## 工作流

### 1. 网页搜索

当用户需要进行信息检索时：

1. 使用 MiniMax MCP `web_search` 工具进行搜索
2. 分析搜索结果，提取关键信息
3. 如果需要更详细的信息，使用 Jina Reader 访问目标页面

```bash
# 使用 MiniMax MCP 进行搜索
mcp__MiniMax__web_search --query "你的搜索查询"
```

### 2. 网页内容提取

对于需要深入分析的网页：

1. 使用 Jina Reader 抓取页面内容
2. 使用 LLM 提取关键信息

```
Jina Reader URL: https://r.jina.ai/{url}
```

### 3. 学术搜索

如需搜索学术论文：

1. 检查是否配置了 Serper API
2. 如果已配置，使用 Serper Scholar 进行搜索
3. 如果未配置，建议用户使用通用搜索 + 手动筛选学术资源

### 4. 文件解析

对于上传的文档：

1. 使用 Dashscope 文件解析 API
2. 提取文档内容进行分析
3. 对于音视频，使用 qwen-omni 模型进行分析

## 最佳实践

1. **先搜索再深入**: 先用搜索获取概览，再对重要资源进行深度提取
2. **验证信息**: 多个来源交叉验证重要信息
3. **记录来源**: 始终记录信息来源，便于后续引用
4. **分步执行**: 复杂研究任务分步进行，每步验证后再继续

## 常见场景

- 研究某个技术主题
- 查找特定问题的解决方案
- 搜索学术论文
- 分析文档内容
- 了解最新行业动态
